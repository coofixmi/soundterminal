# Soundpad (Linux: Mint / Ubuntu / Fedora / Arch)

Минималистичный десктопный саундпад на Python (PyQt6) с изолированной аудио-маршрутизацией через `pactl` (PulseAudio / PipeWire-Pulse), поиском звуков на [MyInstants](https://myinstants.com), локальным кэшированием, избранным и пользовательскими группами.

## Какую папку использовать
- **Linux Mint / Ubuntu / Fedora (и совместимые):** работайте в **корне проекта** (`проэкт_soud/`) — запускайте скрипты и настраивайте всё отсюда.
- **Arch Linux:** **перейдите в папку `arch/` и работайте там** (`cd arch`). Это отдельная версия со своими `run.sh`, `install.sh`, `README.md`, зависимостями/окружением и локальными файлами (`config.json`, `data.json`, `cache/`). Команды установки, запуска и настройки для Arch нужно выполнять из `arch/`.

## Возможности
- Минималистичный интерфейс (TUI-эстетика, QSS) с темами.
- Изолированная аудиомаршрутизация:
  - в виртуальный микрофон попадают **только** ваш физический микрофон и звуки саундпада;
  - звуки браузера/игр/системы в виртуальный микрофон не попадают;
  - петля микрофона не выводится в наушники (нет эха/самопрослушивания голоса).
- Воспроизведение звуков с MyInstants (тренды и поиск) с кэшированием в `cache/`.
- **Загрузка собственных звуков:** кнопка `Загрузить звук` (и поддержка drag-and-drop аудиофайлов в окно) копирует файлы в локальную папку версии `sounds/downloads/` и автоматически добавляет их в группу/вкладку `Загрузки` (группа создаётся при необходимости). Загруженные звуки сохраняются и доступны офлайн.
- Вкладки: `MyInstants`, `Избранное`, пользовательские группы `[ + Группа ]`, `Загрузки` (для импортированных звуков).
- **Усиление звуков в микрофон** (настройка `Усиление звуков в микрофон`, по умолчанию 100%): увеличивает только громкость звуков саундпада в `VirtualMicMix` (слышно собеседникам), не меняя громкость в ваших наушниках и не усиливая ваш голос.
- **Иконка в системном трее:** меню (Показать/Скрыть, Стоп, Выход). Закрытие окна сворачивает приложение в трей; полный выход — через меню трея.
- Сохранение настроек устройств/режима/усиления в `config.json` и избранного/групп/данных звуков в `data.json`.

## Зависимости

### Общие требования
- Python 3
- `mpv` и `libmpv`
- `pactl` (обычно `pulseaudio-utils` или `pipewire-pulse` / `pipewire-pulseaudio`)
- Python-пакеты: PyQt6, requests, beautifulsoup4, python-mpv (см. `requirements.txt`)

### Linux Mint / Ubuntu / Debian-based
```bash
sudo apt update
sudo apt install -y mpv libmpv-dev pulseaudio-utils python3 python3-pip
python3 -m pip install --user -r requirements.txt
```
(При использовании PipeWire `pactl` обычно предоставляется через `pipewire-pulse`.)

### Fedora
```bash
sudo dnf install -y mpv mpv-libs pipewire-pulseaudio python3 python3-pip python3-pyqt6 python3-requests python3-beautifulsoup4
python3 -m pip install --user -r requirements.txt
```
> Примечание: имена пакетов могут отличаться в зависимости от версии Fedora/репозиториев (например, `python3-mpv` может отсутствовать — в этом случае установите `python-mpv` через `pip`). Если используется PulseAudio вместо PipeWire, может потребоваться `pulseaudio-utils`.

### Arch Linux
**Важно:** для Arch используйте версию в папке `arch/` — перейдите в неё и выполняйте команды там.

```bash
cd arch
sudo pacman -S --needed mpv pipewire-pulse python python-pyqt6 python-requests python-beautifulsoup4 python-mpv qt6-wayland
```
Подробности — в [`arch/README.md`](arch/README.md).

## Запуск

### Основная версия (Mint / Ubuntu / Fedora)
Из папки проекта:
```bash
chmod +x run.sh
./run.sh
```
или вручную:
```bash
export LC_NUMERIC=C
python3 -m pip install --user -r requirements.txt   # при необходимости
python3 main.py
```

### Arch-версия
Для Arch нужно работать из папки `arch/`:
```bash
cd arch
chmod +x run.sh
./run.sh
```
(Подробнее: [`arch/README.md`](arch/README.md))

## Установка команды запуска (`soundterminal`)
Чтобы запускать саундпад из терминала одной командой (без `./run.sh`), используйте скрипт `install.sh` в нужной версии. Скрипты создают лаунчеры в `~/.local/bin` (или `$XDG_BIN_HOME`) — убедитесь, что этот каталог есть в `PATH`.

### Mint / Ubuntu / Fedora (основная версия)
```bash
cd "/путь/к/проэкт_soud"
chmod +x install.sh
./install.sh
```
Будут установлены команды:
- `soundterminal` — запуск основной версии
- `soundterminal-mint` — запуск основной версии

### Arch (версия в `arch/`)
Перейдите в папку `arch/` и запускайте установку оттуда:
```bash
cd "/путь/к/проэкт_soud/arch"
chmod +x install.sh
./install.sh
```
Будут установлены команды:
- `soundterminal` — запуск Arch-версии
- `soundterminal-arch` — запуск Arch-версии

> `soundterminal` указывает на ту версию, чей `install.sh` был запущен последним. Для явного выбора используйте `soundterminal-mint` или `soundterminal-arch`.

Если `~/.local/bin` не в `PATH`, добавьте в конфиг оболочки (например `~/.bashrc`, `~/.zshrc`):
```bash
export PATH="$HOME/.local/bin:$PATH"
```

## Настройка микрофона в Discord / Telegram / играх
Чтобы собеседники слышали **и ваш голос, и звуки саундпада**:
1. Запустите приложение (оно создаст виртуальные устройства `SoundpadAppSink` и `VirtualMicMix`).
2. В настройках голосового приложения выберите устройство ввода: **`Monitor of VirtualMicMix`** (может отображаться как «Монитор VirtualMicMix»).
3. В саундпаде выберите:
   - **Наушники (куда слышать звуки)** — ваши реальные наушники/колонки;
   - **Микрофон (ваш голос)** — ваш физический микрофон;
   - **Режим вывода приложения** — `Virtual Mic + Наушники (SoundpadAppSink)`.

> Важно: системный вывод по умолчанию должен оставаться на ваших обычных наушниках, тогда звуки браузера/игр не попадут в виртуальный микрофон.

## Управление и настройки
- Клик по кнопке звука — воспроизведение (плеер привязан к `pulse/SoundpadAppSink`).
- `Esc` или кнопка `[STOP]` — мгновенная остановка.
- `[*]` / ПКМ — избранное и группы; `[ + Группа ]` — создать вкладку.
- **`Загрузить звук`** — выбрать свои аудиофайлы (`mp3`, `wav`, `ogg`, `flac`, `m4a`, `aac`, `opus`, `wma`, `aiff/aif`); можно также перетащить файлы в окно (drag-and-drop). Файлы копируются в `sounds/downloads/` (в папке используемой версии), после чего появляются в группе `Загрузки`.
- **ПКМ по звуку → «Скачать…»** — сохранить/экспортировать звук в выбранную папку загрузки (по умолчанию `~/Downloads`).
- **Настройки → Устройства:** выбор наушников/микрофона, режим, **папка загрузки по умолчанию** для «Скачать…», ползунок **«Усиление звуков в микрофон»** (усиливает только звуки саундпада в `VirtualMicMix`, не меняя громкость в наушниках и громкость вашего голоса).
- **Трей:** закрытие окна сворачивает в трей; выход — из меню трея.

## Примечания
- При полном выходе (меню трея → «Выход») виртуальные модули PulseAudio/PipeWire выгружаются автоматически.
- Звуки из MyInstants кэшируются в `cache/`, а собственные загруженные файлы хранятся в `sounds/downloads/` (в папке используемой версии: корень или `arch/`) — всё доступно офлайн.
- Слишком высокое усиление в микрофон может давать клиппинг; шумоподавление в голосовых приложениях/модах (Discord, Plasmo Voice и т.п.) может искажать или подавлять звуки саундпада — при необходимости снизьте усиление/шумодав.
- Разметка MyInstants может измениться; при ошибках парсинга/сети попробуйте повторить позже.
