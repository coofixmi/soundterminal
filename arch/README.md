# Soundpad (Arch Linux / Wayland / PipeWire-Pulse)

Версия саундпада для **Arch Linux** с акцентом на **Wayland**-сессии и аудиостек **PipeWire** (через `pipewire-pulse`).

Минималистичный десктопный саундпад на Python (PyQt6) с изолированной аудио-маршрутизацией через `pactl`, поиском звуков на [MyInstants](https://myinstants.com), локальным кэшированием и управлением избранным/группами.

**Важно:** это отдельная версия проекта. Для Arch Linux нужно **перейти в папку `arch/` и выполнять все действия там** (установка зависимостей, запуск, установка команды, настройка). Настройки (`config.json`), данные (`data.json`) и кэш (`cache/`) создаются и хранятся локально в этой папке. Исходная (Mint/Ubuntu/Fedora) версия в корне проекта не изменяется.

> Инструкции для Mint/Ubuntu/Fedora и общий обзор проекта — в [основном README](../README.md).

## Обновление из приложения
- В приложении: **Настройки → Устройства → Обновление → «Обновить из GitHub»**.
- Обновление скачивается из репозитория `coofixmi/soundterminal` (ветка `main`) и применяет файлы из папки `arch`.
- Пользовательские данные сохраняются (`config.json`, `data.json`, `cache/`, `sounds/`, `backups/`). После обновления перезапустите приложение.
- Для работы обновления в GitHub-репозитории должна существовать папка `arch/`; если её пока нет, приложение сообщит об этом.

## Возможности
- Минималистичный интерфейс (TUI-эстетика, QSS) с темами.
- Изолированная маршрутизация аудио:
  - в виртуальный микрофон попадают **только** ваш физический микрофон и звуки саундпада;
  - звуки браузера/игр/системы в виртуальный микрофон не попадают;
  - петля микрофона не выводится в наушники (нет эха/самопрослушивания голоса).
- Воспроизведение звуков с MyInstants (тренды и поиск) с кэшированием в `cache/`.
- **Загрузка собственных звуков:** кнопка `Загрузить звук` (и drag-and-drop аудиофайлов в окно) копирует файлы в `sounds/downloads/` внутри папки `arch/` и автоматически добавляет их в группу/вкладку `Загрузки` (создаётся при необходимости). Загруженные звуки сохраняются и доступны офлайн.
- Вкладки: `MyInstants`, `Избранное`, пользовательские группы `[ + Группа ]`, `Загрузки`.
- **Усиление звуков в микрофон** (настройка в `Настройки → Устройства`): усиливает только звуки саундпада в `VirtualMicMix`, не меняя громкость в наушниках и не усиливая ваш голос.
- **Иконка в системном трее:** Показать/Скрыть, Стоп, Выход. Закрытие окна сворачивает приложение в трей; полный выход — через меню трея.
- Сохранение настроек устройств/режима/усиления в `config.json` и избранного/групп в `data.json`.

## Зависимости (Arch Linux)

### Системные пакеты (рекомендуется)
```bash
sudo pacman -S --needed \
  mpv \
  pipewire-pulse \
  python \
  python-pyqt6 \
  python-requests \
  python-beautifulsoup4 \
  python-mpv \
  qt6-wayland
```

Пояснения:
- `mpv` — предоставляет libmpv/плеер для воспроизведения.
- `pipewire-pulse` — даёт `pactl` и PulseAudio-совместимый слой для PipeWire (нужен для маршрутизации `module-null-sink`/`module-loopback`).
- `qt6-wayland` — нативный запуск Qt6-приложений в Wayland-сессии.
- Python-библиотеки предпочтительно ставить системными пакетами Arch; `requirements.txt` оставлен для альтернативной установки через `pip`.

### Альтернатива (pip / venv)
На Arch системный Python обычно помечен как *externally managed* (PEP 668), поэтому `pip install --user` в системное окружение может быть запрещён. Рекомендуется ставить зависимости через `pacman`. Если нужны Python-пакеты через pip, используйте виртуальное окружение в папке `arch`:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
./.venv/bin/python main.py
```

`run.sh` автоматически использует `./.venv/bin/python`, если такое окружение найдено. Системные зависимости вроде `mpv`, `pipewire-pulse`, `qt6-wayland` всё равно нужны.

## Требования к окружению
- Wayland-сессия (рекомендуется) или X11/XWayland.
- Запущенный пользовательский аудиостек PipeWire с `pipewire-pulse` (обычно уже активен в стандартной сессии Arch). Проверка:
  ```bash
  pactl info
  ```
- `run.sh` автоматически задаёт `LC_NUMERIC=C` (требование libmpv) и предпочитает `QT_QPA_PLATFORM=wayland;xcb` в Wayland-сессии.

## Запуск
Из папки `arch`:
```bash
chmod +x run.sh
./run.sh
```
или вручную:
```bash
export LC_NUMERIC=C
python main.py
```

При первом запуске в папке `arch` будут созданы `config.json`, `data.json` и каталог `cache/`.

## Установка команды запуска (`soundterminal` / `soundterminal-arch`)
Чтобы запускать Arch-версию из терминала без `./run.sh`, используйте скрипт установки:
```bash
cd "/путь/к/проэкт_soud/arch"
chmod +x install.sh
./install.sh
```

Будут установлены команды в `~/.local/bin` (или `$XDG_BIN_HOME`):
- `soundterminal` — запуск этой (Arch) версии
- `soundterminal-arch` — запуск этой (Arch) версии

> `soundterminal` указывает на версию, чей `install.sh` был запущен последним. Для основной (Mint/Ubuntu/Fedora) версии используйте `install.sh` в корне проекта — он установит `soundterminal-mint`.

Если `~/.local/bin` не в `PATH`, добавьте в конфиг оболочки:
```bash
export PATH="$HOME/.local/bin:$PATH"
```

## Настройка микрофона в Discord / Telegram / играх
Чтобы собеседники слышали **и ваш голос, и звуки саундпада**:
1. Запустите приложение (оно создаст виртуальные устройства `SoundpadAppSink` и `VirtualMicMix`).
2. В настройках голосового приложения выберите устройство ввода: **`Monitor of VirtualMicMix`** (может отображаться как «Монитор VirtualMicMix»).
3. В верхней панели саундпада выберите:
   - **Наушники (куда слышать звуки)** — ваши реальные наушники/колонки;
   - **Микрофон (ваш голос)** — ваш физический микрофон;
   - **Режим вывода приложения** — `Virtual Mic + Наушники (SoundpadAppSink)`.

> Важно: системный вывод по умолчанию должен оставаться на ваших обычных наушниках, тогда звуки браузера/игр не попадут в виртуальный микрофон.

## Управление и настройки
- Клик по кнопке звука — воспроизведение (плеер привязан к `pulse/SoundpadAppSink`).
- `Esc` или кнопка `[STOP]` — мгновенная остановка.
- `[*]` / ПКМ — избранное и группы; `[ + Группа ]` — создать вкладку.
- **`Загрузить звук`** — выбрать свои аудиофайлы (`mp3`, `wav`, `ogg`, `flac`, `m4a`, `aac`, `opus`, `wma`, `aiff/aif`) или перетащить их в окно. Файлы копируются в `sounds/downloads/` внутри `arch/` и появляются в группе `Загрузки`.
- **ПКМ по звуку → «Скачать…»** — сохранить/экспортировать звук в выбранную папку загрузки (по умолчанию `~/Downloads`).
- **Настройки → Устройства:** выбор устройств/режима, **папка загрузки по умолчанию** для «Скачать…» и **«Усиление звуков в микрофон»** (только звуки саундпада в виртуальном микрофоне; наушники и ваш голос не меняются).
- **Трей:** закрытие окна сворачивает в трей, полный выход — из меню трея.

## Примечания и устранение неполадок
- При полном выходе (меню трея → «Выход») виртуальные модули PulseAudio/PipeWire выгружаются автоматически.
- Звуки из MyInstants кэшируются в `cache/`, собственные загруженные — хранятся в `sounds/downloads/` внутри папки `arch/`; всё доступно офлайн.
- Если маршрутизация не создаётся: убедитесь, что работает `pipewire-pulse` и `pactl info` выполняется без ошибок.
- Слишком высокое усиление в микрофон может вызывать клиппинг; шумоподавление (Discord, Plasmo Voice и т.п.) может искажать/подавлять звуки — при необходимости снизьте усиление или шумодав.
- Если есть проблемы с отображением в Wayland, можно запустить через XWayland: `QT_QPA_PLATFORM=xcb ./run.sh`.
- Разметка MyInstants может измениться; при ошибках парсинга/сети попробуйте повторить поиск позже.
